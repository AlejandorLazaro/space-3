# Space³

"A space for your neighbor and you - so get out there"

An event-first semi-social media service that's intentionally ephemeral.
No long message history, no DMs, no fancy bells and whistles that keep
people *on* Space³, but ones that push people *out* with each other.

## Stack

- **Next.js 16** (App Router) + TypeScript + Tailwind
- **Supabase** — Postgres, Auth, Realtime, Row Level Security
